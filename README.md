## Setup Instructions

### Prerequisites
- Node.js installed
- Local MongoDB running on `mongodb://localhost:27017/notes_db`

### 1. Backend Server
cd server
npm install
npm start

Runs on http://localhost:8000

### 2. Frontend Client
cd client
npm install
npm run dev

Runs on http://localhost:5173
